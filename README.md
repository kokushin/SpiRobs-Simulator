# SpiRob Dynamics Lab

論文 *SpiRobs: Logarithmic spiral-shaped robots for versatile grasping across scales* と、付属の `3-cable SpiRob.STL` を基にしたWebGLシミュレータです。

## 起動

```bash
npm install
npm run dev
```

本番用ビルドは `npm run build`、確認は `npm run preview` です。

## モデル化の根拠

添付STL（54,846 triangles / 約231.3 × 27.8 × 31.4 mm）を連結成分解析し、20個の独立したテーパーユニットと、それらをつなぐ1本の弾性軸を抽出しています。画面上の白い形状は代替モデルではなく、元のSTL頂点を各物理ユニットの姿勢へGPUスキニングしたものです。

論文に基づく固定条件：

- 対数螺旋 `ρ = ae^(bθ)` と30°刻みの離散ユニット
- 3本のケーブルを断面上へ120°間隔で配置
- 3ケーブル機の弾性軸厚はユニット幅の10%
- TPU 95AのプリントボディとUHMWPEケーブル
- 隣接ユニット接触による最大局所曲げ（約30°）
- 先端ほど曲率が大きくなる可変曲率モデル（一定曲率/PCCではない）

計算は固定120 Hzの離散Cosseratロッド型関節ソルバです。各ケーブル張力を断面半径から曲げモーメントへ変換し、離散関節の回転剛性 `EI / ℓ` と幾何相似から得る半径3乗則で剛性を分布させます。ケーブル損失はユニット番号ではなく累積屈曲角を用いるCapstan則 `T = T₀ exp(-μΣ|Δθ|)` で計算します。重力モーメントには各ユニットのSTL体積比から得た質量分布と、全遠位質量のモーメントを使用します。

ロボットと対象の接触は、保守的なBox衝突形状ではなくSTLユニット寸法に沿う連続TPU近接接触（既定220 N/m）で解きます。球・円柱・箱それぞれの符号付き距離を使うため、形状を球で代用せず非貫通と接触法線を一致させています。接触反力は全上流関節へ戻されます。巻き付き段階では対象表面の非貫通拘束とリンク長拘束を反復し、基部側は両端固定FABRIK、末端側は実リンク長を弦長とする表面追従拘束で解きます。このためメッシュを伸ばさず、局所30°の曲げ制限内で複数ユニットが対象外周へ連続配置されます。摩擦閉包後の分布接触は、プリテンションから保持力上限を求める位置ベース拘束で安定化しています。床と対象はCannon剛体接触、摩擦、質量、重力を持ちます。

## 物体把持

既定の52 mm・45 g球を選び、左パネルの `把持シミュレーション実行`（または下部の `AUTO GRASP`）を押すと、初期状態へ自動復帰して次の閉ループ試験を一括実行します。実行中はボタンに現在の段階と進捗が表示され、保持完了後は同じボタンで再実行できます。

1. `PACK` — 1本のケーブル張力を増やし、先端から螺旋状にパックする。提示治具は対象を再現可能な把持高さへ移動する。
2. `REACH` — PACK側を保ったまま、反対側を担う残り2本を等しく増張し、基部側からほどいて対象へ接近する。
3. `WRAP` — 反対側2本を保ったままPACK側を徐々に減張し、接触点を滑らせず対象表面上を登らせる。
4. `GRASP` — 反対側2本を増張し、3ユニット以上の摩擦閉包を検出して試験治具から動的物体へ解放する。
5. `HOLDING` — 物体の質量・重力・床摩擦を有効にしたまま保持を継続する。

右パネルでは接触ユニット、法線力、把持品質、対象のXYZ座標を確認できます。自動試験では巻き付き形状が完成するまで対象位置を提示治具相当で静止させ、`HOLDING`移行時に動的物体へ解放します。手動張力入力、別プリセット、ドラッグ、リセットを行うと把持拘束と対象表面追従拘束は解除されます。

## 実機へ合わせる校正

論文とSTLだけでは、プリント方向・充填率・温度・層間接着・ケーブル穴面粗さによる実効物性は一意に決まりません。実機製作で使う場合は、左パネルの `CALIBRATION` を次の順で同定してください。

1. ロボットを水平固定し、無張力時の先端位置が一致するよう「基部曲げ剛性」を調整する。
2. 小さなステップ張力を1本へ与え、整定時間とオーバーシュートが一致するよう「関節減衰」を調整する。
3. 同じモータ張力で基部と先端の曲率分布を比較し、「ケーブル摩擦」を調整する。
4. 既知材質の物体を巻き、滑り始める条件が一致するよう「TPU接触摩擦」を調整する。
5. 設定を書き出し、使用するプリント条件・ケーブル・造形ロットと一緒に版管理する。

先端軌道は60 fps以上の動画から抽出し、少なくとも水平・吊下・垂直の3姿勢で検証してください。動的な鞭打ち動作を製作判断に使う場合は、モータの実測張力波形も入力値へ合わせる必要があります。

## 現在の適用範囲

本モデルは形状設計、張力配分、到達方向、重力たわみ、巻き込み速度、物体へ与える接触運動の比較に向きます。ケーブルの局所的なスティックスリップ、TPUの粘弾性ヒステリシス、造形異方性、座屈後の面接触は集約パラメータです。安全率や最大可搬質量の最終判断は、校正後も実機試験と併用してください。
